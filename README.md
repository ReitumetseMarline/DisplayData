##COVID Data Visualization (Matplotlib)

This is a simple Python project that visualizes COVID dataset values (daily confirmed cases and daily deaths) using the Matplotlib library.

The program reads data from a JSON file and displays it as a line graph for easy trend analysis.

##Features

Reads COVID data from a JSON file

Converts date strings into proper date objects

Plots:

Daily Confirmed Cases

Daily Deaths

Formats the X-axis with readable dates

Displays both datasets on the same graph

🛠 Technologies Used

Python 3

Matplotlib

JSON

datetime module


##How to Run the Project

Make sure you have Python 3 installed.

Install matplotlib if you don’t have it:

pip install matplotlib


##Run the program:

python3 display.py


The graph will open in a new window displaying the data visualization.


The script generates a line graph showing:

Daily COVID confirmed cases

Daily COVID deaths

Date displayed on the X-axis

Count displayed on the Y-axis

##Purpose of This Project

This project demonstrates:

Data extraction from JSON

Data cleaning and type conversion

Date formatting in Python

Data visualization using Matplotlib
